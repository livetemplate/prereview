# Check consistency

Read the whole file before proposing anything, then check it for consistency from start
to end: the same names, terms, numbers, claims and decisions throughout, with no section
contradicting another. Where two places disagree, say which one you think is right and
fix the other.

If the file has an appendix, check that everything in it supports something in the main
body. Flag appendix content that the main body never uses, and main-body content that
only makes sense after reading the appendix.

Propose each change as a `prereview suggest` edit (a before→after on the exact lines) so
I can accept or reject it. Do not modify files directly.
